# الخدمات في كود نظام معرض قويدر

الكود مقسّم إلى أربع طبقات:

| الطبقة | المجلد | ماذا فيها |
|---|---|---|
| **المجال** (Domain) | `src/Qwader.Domain` | الكيانات (المنتج، الفاتورة…) وقواعدها الثابتة (حساب التكلفة، أسماء الصلاحيات). لا تعرف قاعدة البيانات ولا الويب. |
| **التطبيق** (Application) | `src/Qwader.Application` | منطق العمل: كل الخدمات أدناه تقريبًا. تتعامل مع قاعدة البيانات عبر واجهة `IAppDbContext`. |
| **البنية التحتية** (Infrastructure) | `src/Qwader.Infrastructure` | ما يلمس العالم الخارجي: قاعدة البيانات، الهوية وكلمات المرور، الملفات، Excel، الإشعارات، النسخ الاحتياطي. |
| **الواجهة البرمجية** (Api) | `src/Qwader.Api` | الـ Controllers (عناوين `/api/...`) والصلاحيات والأمان، وتقديم واجهة React. |

**ملاحظة:** الـ Controllers لا تحتوي منطقًا؛ كل عنوان `/api/...` يتحقق من الصلاحية ثم يستدعي خدمة.

## 1. خدمات العمل (طبقة التطبيق)

### المنتجات والمخزون
| الخدمة | لشو |
|---|---|
| **ProductService** | المنتجات: القائمة مع البحث (بدون مسافات وهمزات) والفلاتر والترتيب (الأحدث أولًا)، التفاصيل، الإضافة والتعديل (مع الرصيد الافتتاحي والوحدات الإضافية كالدزينة)، الأرشفة (تصفّر المخزون)، البحث بالكود والباركود. |
| **ProductExcelService** | Excel المنتجات: التصدير حسب الفلتر، النموذج (مع ورقة «الأصناف والوحدات» والقوائم المنسدلة)، والاستيراد: إنشاء أو تحديث (بالكود أو الاسم)، إضافة الأصناف والوحدات الجديدة، و«الكمية الفعلية» (رصيد افتتاحي أو جرد واحد). |
| **CategoryService** | الأصناف: إضافة وتعديل وقائمة. |
| **InventoryService** | إدارة المخزون: ملخص المخزون، سجل الحركات وجدوله ومجموعه، حركات التالف والمفقود والزيادة، الجرد (إنشاء، إدخال المعدود، اعتماد، إلغاء)، و«تصحيح التكلفة». |
| **InventoryLedger** (دفتر المخزون) | **الكاتب الوحيد** لأرصدة المخزون وحركاته ومتوسط التكلفة. يُدخل البضاعة (ويعيد حساب المتوسط المرجّح)، يُخرجها، ويصحّح التكلفة. يقفل صف المنتج أثناء العملية حتى لا تتداخل عمليتان على نفس المنتج. |

### المبيعات والعملاء
| الخدمة | لشو |
|---|---|
| **SaleService** | فواتير البيع: الإنشاء (الأسعار والخصومات وحد الخصم وأقل سعر والوحدات، الدفعات والحوالات، خصم المخزون، دين العميل)، القائمة والتفاصيل، المرتجع، الإلغاء، الملخص اليومي، **بيانات البيع دون اتصال** (النسخة الكاملة والتحديثات)، مراجعة فواتير دون اتصال، وإشعارات البيع والمخزون المنخفض. |
| **CustomerService** | العملاء: إضافة وتعديل، البحث بالاسم أو الجوال، كشف الحساب، إنشاء العميل تلقائيًا من الاسم والجوال عند البيع. |
| **CustomerLedger** (دفتر العملاء) | يكتب حركة في كشف حساب العميل ويحدّث رصيده في نفس اللحظة. يمنع أي دين على «زبون نقدي». |

### المشتريات والموردون
| الخدمة | لشو |
|---|---|
| **PurchaseService** | فواتير الشراء: مسودة، اعتماد (إدخال البضاعة بالتكلفة الصافية، تحديث آخر سعر شراء، دين المورد، الدفعة)، الإلغاء، المردود للمورد، الوحدات (الشراء بالدزينة). |
| **SupplierService** | الموردون: إضافة وتعديل وقائمة وكشف الحساب. |
| **SupplierLedger** (دفتر الموردين) | يكتب حركة في كشف حساب المورد ويحدّث رصيده. |

### المالية
| الخدمة | لشو |
|---|---|
| **AccountService** | الحسابات المالية: إضافة وتعديل، الرصيد الافتتاحي، كشف الحساب، التحويل بين حسابين. |
| **AccountLedger** (دفتر الحسابات) | يُدخل ويُخرج المبالغ من الحساب المالي ويحدّث رصيده. **يرفض أي دفعة أكبر من الرصيد** (لا يصبح الحساب سالبًا بدفعة). |
| **TransferService** | الحوالات الواردة: تسجيلها (من البيع أو يدويًا)، التأكيد أو الرفض، وربطها بسند القبض والفاتورة. |
| **VoucherService** | سندات القبض (تحصيل الديون وتوزيعها: أولًا على الفاتورة التي دُفع لها إن وُجدت، ثم الرصيد الافتتاحي، ثم أقدم الفواتير المفتوحة)، سندات الصرف (دفعة مورد، إعادة مبلغ لعميل، سلفة)، والمصروفات، مع إلغاء كل منها. |
| **PayrollService** | الرواتب: العمال، السلف (دين على العامل) والخصومات والمكافآت، المخالصة (حساب الصافي والدفع من حساب)، الإلغاء، و«بياناتي المالية» للعامل نفسه، وإشعار العامل عند الصرف. |

### التقارير والبحث والإشعارات
| الخدمة | لشو |
|---|---|
| **ReportService** | التقارير: الأرباح والمصروفات، اليومي، الأكثر مبيعًا، حسب الصنف والموظف، ذمم العملاء ومستحقات الموردين، قيمة المخزون، التدفق النقدي، رأس المال في البضاعة (الزيادة والنقص). |
| **SearchService** | البحث السريع من أعلى الشاشة (منتجات، عملاء، موردون، فواتير، سندات، حوالات)، وعدّاد التنبيهات (المخزون المنخفض والمسودات). |
| **NotificationFeedService** | قائمة إشعارات المستخدم (الجرس وشاشة الإشعارات): العرض، تعليم كمقروء. |
| **PushSubscriptionService** | اشتراك أجهزة المستخدم في إشعارات الجوال واختيار المواضيع. |

### الإعدادات والإدارة
| الخدمة | لشو |
|---|---|
| **SettingsService** | إعدادات المعرض: القراءة والتعديل، وتطبيق حد التنبيه على كل المنتجات. |
| **LookupService** | القوائم الصغيرة التي تحتاجها الشاشات مرة واحدة (الأصناف، الوحدات، الحسابات، تصنيفات المصروفات…)، وإضافة وحدة قياس جديدة. |
| **AuditLogService** | عرض سجل التدقيق مع الفلاتر، وأسماء العمليات بالعربي، واسم المنتج أو رقم المستند بدل الرقم الداخلي. |
| **IntegrityService** | **فحص سلامة الحسابات**: يعيد حساب كل رصيد من حركاته ويقارنه بالمحفوظ (للقراءة فقط). يمكن تعطيله لكل نسخة. |
| **AuthService** | تسجيل الدخول والخروج، تجديد الجلسة، تغيير كلمة المرور، وبيانات المستخدم الحالي. |

## 2. الخدمات المساعدة (البنية التحتية)

| الخدمة | لشو |
|---|---|
| **AppDbContext** | الاتصال بقاعدة البيانات وتعريف كل الجداول؛ يطبّق تحديثات القاعدة (Migrations) عند التشغيل. |
| **UserService** | المستخدمون: إضافة وتعديل وتعطيل وإعادة تعيين كلمة المرور، مع منع ترك النظام بلا مدير. |
| **RoleService** | الأدوار وصلاحياتها؛ دور «مدير النظام» يملك كل الصلاحيات دائمًا. |
| **JwtTokenService** | إصدار رمز الدخول (صالح 15 دقيقة) ورمز التجديد. |
| **DocumentNumberGenerator** | أرقام المستندات المتسلسلة بلا تكرار ولا فجوات (INV-2026-000001…). |
| **IdempotencyService** | حفظ والبحث عن «مفتاح العملية» لمنع تنفيذ نفس الحفظ مرتين. |
| **AuditService** | كتابة سطر في سجل التدقيق مع القيم قبل وبعد والمستخدم وعنوان IP. |
| **LocalFileStorage** | حفظ الملفات المرفوعة على قرص الخادم (خارج مجلد الموقع) وقراءتها، وحذف محتواها عند التصفير. |
| **ExcelService** | كتابة وقراءة ملفات Excel (اتجاه عربي، صف عناوين ثابت، قوائم منسدلة من ورقة ثانية، أرقام بدون نقطة زائدة). |
| **SystemBackupService** | النسخة الاحتياطية: ملف ZIP فيه كل الجداول (بدون كلمات المرور) ونسخ Excel للقوائم الرئيسية والملفات المرفوعة. |
| **SystemResetService** | تصفير النظام (الحركات فقط أو كل شيء) لمدير النظام بكلمة المرور، مع **نسخة احتياطية تلقائية قبله**؛ وحذف فترة من سجل التدقيق. يمكن تعطيل التصفير لكل نسخة. |
| **PushNotifier** | يضع الإشعار في طابور (للمشتركين بموضوع وصلاحية، أو لمستخدم معيّن) دون أن ينتظر الإرسال. |
| **PushQueue** / **PushDispatcher** | الطابور، والخدمة الخلفية التي ترسل منه للأجهزة وتحفظ الإشعار في قائمة كل مستخدم، وتمسح القديم (أكثر من 90 يومًا). |
| **WebPushSender** / **VapidKeys** | الإرسال الفعلي لإشعارات الجوال (Web Push) ومفاتيحه. |
| **SystemClock** | الوقت الحالي وتحويله لتوقيت فلسطين (ليُختبر بوقت ثابت). |
| **CurrentUser** (في Api) | من المستخدم الحالي وصلاحياته، من رمز الدخول. |

## 3. طبقة الواجهة البرمجية (Api) — ما يحمي كل طلب

| العنصر | لشو |
|---|---|
| **HasPermission** | يتحقق أن للمستخدم الصلاحية المطلوبة قبل تنفيذ أي عنوان. كل `/api` مغلق إلا ما يُفتح صراحة (الدخول، الصحة). |
| **ValidationFilter** | يرفض الطلب الناقص أو الخاطئ برسائل عربية مربوطة بالحقول قبل الوصول للخدمة. |
| **AppExceptionHandler** | يحوّل الأخطاء إلى رسائل عربية مفهومة (بدون تفاصيل داخلية). |
| **ترويسات الأمان** (في Program.cs) | CSP و HSTS ومنع العرض داخل iframe وغيرها على كل رد. |
| **ضغط الردود** | يضغط ردود الـ API (Brotli/Gzip) لتصل أسرع على الجوال. |
| **Rate limiting** | حد لمحاولات الدخول في الدقيقة، مع قفل الحساب بعد 5 محاولات فاشلة. |
| **ProxyGate** | في نسخة التست فقط: يقبل الطلبات القادمة عبر Cloudflare بمفتاح سري. |

## 4. الواجهة (React — `web/src`)

| الجزء | لشو |
|---|---|
| `api/` | استدعاءات الخادم لكل قسم (منتجات، مبيعات، مخزون…). |
| `auth/` | الدخول، الجلسة، والصلاحيات في الواجهة. |
| `features/` | الشاشات: نقطة البيع، المنتجات، المخزون، المشتريات، المبيعات، العملاء، المالية، الرواتب، التقارير، الإعدادات، التعليمات… |
| `lib/offline.ts` | البيع دون اتصال: نسخة المنتجات والعملاء على الجهاز (IndexedDB)، طابور الفواتير، والإرسال عند عودة النت. |
| `components/` | عناصر مشتركة (الأزرار، الحقول، النوافذ، القوائم، ماسح الباركود…). |
| Service Worker (PWA) | تثبيت التطبيق على الجوال، تخزين ملفاته للفتح السريع ودون اتصال، واستقبال الإشعارات. |
